# BookMyShows — Movie Ticket Booking System

A movie ticket booking web application developed using Java, Spring Boot, Spring Data JPA, and MySQL, with a frontend built using HTML, CSS, and JavaScript.

## Features

- Browse movie listings
- Search theaters by city
- View available showtimes
- Select seats for a show
- Book movie tickets
- View booking details and booking history
- Cancel bookings

## Getting Started

### Prerequisites

- Java JDK
- MySQL Server
- IntelliJ IDEA or another Java IDE

### Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/Gauravsharma0204/BookMyShows.git
   ```

2. Open the project in IntelliJ IDEA.

3. Configure your MySQL connection using environment variables or your local configuration.

4. Run the Spring Boot application:

   **Windows**
   ```bash
   mvnw.cmd spring-boot:run
   ```

5. The backend runs on port `8081` by default.
